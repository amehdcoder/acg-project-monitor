# ACG Project Monitor

A professional field monitoring and data collection platform for public health and developmental projects.

## Tech Stack
- **Frontend**: Vite, React, TypeScript
- **Styling**: Tailwind CSS, shadcn-ui
- **Backend**: Supabase (Database, Auth, Storage, Edge Functions)
- **Geospatial**: Leaflet, GeoJSON

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Connect to Supabase: `npx supabase login`
4. Start development: `npm run dev`

## Deployment
Deploy to any static hosting provider (Vercel, Netlify, Cloudflare Pages) and configure Supabase environment variables.
